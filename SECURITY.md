# Security policy

Kombini writes to the game folder, downloads and extracts archives, and handles `kombini://` links,
so we take security reports seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub's
"Report a vulnerability" button on this repository's **Security** tab, and include:

- what an attacker can do, and under which conditions;
- steps or a file that reproduces it;
- the version you tested (shown in Settings).

We'll acknowledge the report as soon as we can and keep you updated until it's fixed and released.

## Supported versions

Only the latest release gets security fixes.
